# Using the Errors section of the admin

This is the operator's guide to the *Errors* section that `django-admin-errors` adds to your
Django admin — for the person who logs in and looks at issues, not the developer installing the
package (that's the project [README](../../README.md)).

If you're new here, start with [Getting started](getting-started.md). Once errors are coming in:

- [Triaging issues](triage-issues.md) — reading the issue list and detail page, and using
  Resolve / Ignore / Reopen.
- [Retention](retention.md) — how much history is kept, and how to clean up on demand.
- [Notifications](notifications.md) — turning email alerts on or off.
- [Troubleshooting](troubleshooting.md) — "it isn't working", step by step.
